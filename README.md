# STM32 Industrial Controller

Personal embedded firmware project based on the STM32F103C8T6 microcontroller.

## Development Tools
- STM32CubeIDE
- Embedded C
- STM32 HAL
- Proteus simulation

## Current Progress
- STM32 project initialized
- GPIO LED blinking implemented
- Firmware compiled successfully

## Planned Features
- GPIO-based system control
- ADC sensor acquisition
- PWM actuator control
- UART monitoring
- Fault detection and safe-state handling
- Watchdog and firmware validation
